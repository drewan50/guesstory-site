# guesstory-site

Public Privacy Policy and Support pages for the Guesstory iOS app, hosted via GitHub Pages for
App Store Connect submission.

- `index.html`: landing page
- `privacy-policy.html`: privacy policy
- `support.html`: support page
- `style.css`, `assets/`: shared styling and images (the screenshots are the anonymized App Store set)

Live at: https://drewan50.github.io/guesstory-site/

The pages are plain static HTML, no build step. Edit the HTML and push to `main`; GitHub Pages
republishes within a minute or two. The in-app links live in `GuesstoryConfig.Links` in the app repo.
